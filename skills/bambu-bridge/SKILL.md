# Bambu Bridge plugin

Read [the operating instructions](../../SKILL.md) before using this plugin. They define device selection, settings workflows, physical-write authorization, UUID recovery and evidence limits.

The plugin root is two directories above this file. Its `setup_bridge.py` and `bridge_client.py` provide setup and CLI fallback; use the plugin's MCP tools when available. Setup details are in [references/setup.md](../../references/setup.md), and tool workflows are in [references/api.md](../../references/api.md).
